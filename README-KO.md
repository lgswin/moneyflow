# Money Flow

개인 계좌, 소비, 해외송금, 대여금 상환을 한곳에서 관리하는 모바일 우선 PWA입니다.

## GitHub Pages

이 저장소는 `main` 브랜치에 변경사항이 올라오면 GitHub Actions가 정적 PWA를 빌드해 GitHub Pages에 자동 배포하도록 구성되어 있습니다.

- 저장소 이름: `moneyflow`
- Pages 주소: `https://lgswin.github.io/moneyflow/`
- Pages 소스: GitHub Actions
- 로컬 정적 빌드: `PAGES_BASE_PATH=/moneyflow/ npm run build:pages`

브라우저 데이터는 `localStorage`에만 보관되며 GitHub 저장소나 배포 파일에 포함되지 않습니다. 기존 주소에서 사용하던 데이터는 JSON 백업 후 새 GitHub Pages 주소에서 복원하세요.

## 주요 기능

- 5개 기본 계좌 선택 및 이름 편집
- 지출, 수입, 송금, 빌림, 상환 거래 기록
- KRW/CAD 송금의 보낸 금액, 받은 금액, 자동 환율, 수수료 기록
- 주요 지출 계좌의 소비 통합 리포트
- 대여 원금(KRW), 실제 정산액(CAD), 상환 기록 및 진행률 관리
- 기기 내 로컬 저장, JSON 백업/복원, CSV 내보내기/가져오기
- 홈 화면 설치와 오프라인 실행 지원

## 계좌 사용 방법

각 계좌를 선택하면 해당 계좌에서 바로 다음 작업을 할 수 있습니다.

- `입금`: 0에서 시작하는 계좌 잔액에 필요한 금액을 추가합니다.
- `송금`: 현재 계좌에서 대상 계좌를 지정합니다. 같은 통화는 같은 금액이 이동하고, KRW와 CAD 사이에서는 송금할 때마다 `1 CAD = KRW` 환율을 새로 입력하면 입금액이 자동 계산됩니다. 이전 송금의 환율은 재사용하지 않습니다.
- `지출`: 주요 지출 계좌에서만 표시되며, 지출 금액과 내역을 기록합니다.

기존 버전의 기준 잔액은 업데이트 시 자동으로 `기존 잔액 이관` 거래로 변환되므로 현재 잔액이 유지됩니다.

## 실행 방법

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 표시되는 로컬 주소를 여세요. 배포용 파일을 확인하려면 `npm run build`를 실행합니다.

## 데이터 안내

데이터는 서버가 아니라 사용 중인 브라우저의 로컬 저장소에 보관됩니다. 브라우저 데이터를 삭제하거나 기기를 바꾸기 전에 리포트 화면에서 JSON 백업을 내려받으세요.
